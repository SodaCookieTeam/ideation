# 일상 탈루틴화 무작위성 주입기

## 한 줄 요약
매일 반복되는 루틴에서 벗어나고 싶은 사람에게 AI가 실행 가능한 랜덤 미션을 제공하고 완료 시 게이미피케이션으로 동기부여하는 서비스.

## 문제
- 직장인, 대학생 등 일상이 루틴화된 사람들이 겪는 문제
- 매일 같은 식당, 같은 길, 같은 행동 패턴의 반복으로 무기력함
- 새로운 것을 시도하고 싶지만 선택 장애로 결정을 못 내림
- 일상에 변화를 주고 싶지만 어디서부터 어떻게 해야 할지 모름

## 해결 방식
1. 사용자가 카테고리(일상, 관계, 음식, 스킬, 모험) 선택
2. AI가 실행 가능한 랜덤 미션 제공 (난이도별)
3. 미션 완료 시 기록하고 통계/뱃지로 게이미피케이션
4. 완료한 미션 지도로 행동 범위 시각화
5. 친구와 같은 미션 공유하는 운명 공유 모드

## 핵심 기능
- [ ] 카테고리별 랜덤 미션 데이터베이스 및 제공
- [ ] 난이도별 분류 (쉬움/중급/도전)
- [ ] 미션 완료 추적 및 히스토리 저장
- [ ] 통계 대시보드 (완료 수, 연속 달성, 카오스 레벨)
- [ ] 위치 기반 식당 룰렛 기능

## 만들 수 있을까
- 필요한 기술/API: 웹 프론트엔드, LocalStorage, Geolocation API, Google Maps API (선택), LLM (맞춤 미션 생성)
- 하루 안에 데모까지 갈 수 있는가: 핵심 기능(랜덤 미션 제공, 완료 추적, 통계)은 프론트엔드만으로 하루 안에 가능
- 걸림돌: AI 맞춤형 미션 생성은 v2, 친구 공유 기능은 백엔드 필요하므로 데모에서는 제외

## 참고
- 게이미피케이션 요소로 사용자 참여 유도
- 행동 변화 유도 서비스로 심리학적 접근
- 비슷한 서비스: Fabulous, Habitica (but 목표 관리 중심, 무작위성 없음)
