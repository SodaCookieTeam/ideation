# 온라인 강의/세미나 자동 요약 및 퀴즈 생성 에이전트

## 한 줄 요약
유튜브·Zoom 녹화본 링크를 입력하면 AI 에이전트가 STT로 변환 후 타임스탬프별 요약 노트와 5지선다 퀴즈·오답 노트를 자동으로 생성해주는 서비스.

## 문제
- 학생, 직장인 등 온라인 강의/웨비나 수강자가 겪는 문제
- 긴 강의 영상을 다 볼 시간이 없음
- 내용을 건성으로 들어 나중에 복습할 때 어디서 무슨 내용이 나왔는지 다시 찾기 힘듦
- 별도로 필기하거나 요약하는 데 시간이 많이 걸림

## 해결 방식
1. 사용자가 유튜브, Zoom 녹화본 등 영상/음성 링크 입력
2. STT(Speech-to-Text)로 음성을 텍스트로 변환
3. 타임스탬프별 핵심 요약 노트 자동 생성
4. 단원별 5지선다 퀴즈 및 오답 노트 자동 생성

## 핵심 기능
- [ ] 영상/음성 링크 입력 및 STT 변환
- [ ] 타임스탬프별 핵심 요약 노트 생성
- [ ] 단원별 5지선다 퀴즈 자동 생성
- [ ] 오답 노트 자동 생성 및 제공

## 만들 수 있을까
- 필요한 기술/API: Whisper(STT), LLM(요약·퀴즈 생성), YouTube Data API / yt-dlp
- 하루 안에 데모까지 갈 수 있는가: Whisper + GPT 조합으로 핵심 기능은 하루 안에 가능
- 걸림돌: 긴 영상의 경우 STT 처리 시간 및 비용, 저작권 문제

## 참고
- OpenAI Whisper, Clova Speech 등 STT API
- 비슷한 서비스: Otter.ai, Notta, 클로바노트
