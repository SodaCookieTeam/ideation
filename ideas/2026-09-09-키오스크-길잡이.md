# 키오스크 길잡이

## 한 줄 요약
고령자와 저시력자가 무인 주문기 앞에서 멈춰 서는 문제를, 키오스크 화면을 찍으면 목표까지 누를 버튼을 하나씩 지목해주는 방식으로 해결한다.

## 문제
- 60대 이상 고령자, 저시력자, 한국어를 읽기 어려운 이주민
- 지금은 뒷사람 눈치를 보다 포기하고 유인 창구를 찾거나 매장을 나온다.
- 매장마다 키오스크 UI가 달라서 한 번 익혀도 다음 가게에서 다시 막힌다. 학습이 쌓이지 않는다.
- 기존 접근은 제조사가 접근성 모드를 넣어주기를 기다리는 것뿐이다.

## 해결 방식
1. 화면 사진 + 하고 싶은 말을 음성으로 입력("따뜻한 아메리카노 하나, 포장")
2. 현재 화면에서 눌러야 할 버튼 **하나만** 지목 — 사진 위에 큰 원 표시 + 음성 안내
3. 다음 화면 사진을 받아 이어서 안내. 목표 달성까지 단계 상태를 유지
4. 좌표를 신뢰할 수 없을 때는 "화면 오른쪽 아래 초록색 버튼"처럼 상대 위치·색상 설명으로 자동 하향

## 핵심 기능
- [ ] 화면 사진 + 음성 목표 입력 (최소 기능)
- [ ] 버튼 위치 지목과 음성 안내
- [ ] 다단계 상태 유지로 결제까지 이어짐
- [ ] 좌표 실패 시 텍스트 설명 대체 경로

## 만들 수 있을까
- 필요한 기술: 이미지 입력이 가능한 LLM(버튼 위치 추정), STT/TTS, 정규화 좌표를 캔버스에 오버레이
- 하루 안에 데모까지: **가능.** 실시간 영상이 아니라 단계마다 정지 사진을 받는 구조로 좁히면 멀티모달 호출 반복으로 끝난다.
- 한국어 TTS/STT의 품질과 무료 한도는 **확인 못 함.** 브라우저 내장 음성 API를 1차로 쓰고 실패 시 대체안을 둔다.
- 걸림돌
  - 버튼 좌표 정확도가 이 아이디어의 성패다. 좌표가 엉뚱한 곳에 찍히면 오히려 신뢰를 깎으므로 상대 위치 설명 폴백을 반드시 만든다.
  - 실제 키오스크를 찍으면 반사와 기울어짐이 생긴다. 데모는 노트북에 띄운 키오스크 화면을 대역으로 쓴다.

## 시연 장면
노트북에 실제 카페 키오스크 화면을 띄워 대역으로 쓴다. 발표자가 폰으로 찍고 "따뜻한 아메리카노"라고 말하면, 폰 화면의 사진 위에 큰 노란 원이 버튼 위에 그려지고 "화면 왼쪽 아래, 커피를 누르세요"가 들린다. 다음 화면에서 원이 옮겨간다. 세 번 눌러 결제까지 간다.

## 참고
- 유사 도구: Seeing AI, 설리번플러스, 네이버 렌즈 — 글자를 읽어주는 데서 멈추고 "무엇을 누르라"까지 가지 않는다.
- 기기를 개조하지 않고 사용자 폰에서 어떤 키오스크든 대응한다는 점이 차별점이다.
