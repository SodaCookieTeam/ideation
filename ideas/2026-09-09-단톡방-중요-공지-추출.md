# 단톡방 중요 공지 자동 추출 도구

## 한 줄 요약
수백 개 쌓인 단톡방 메시지 속에서 "@전체", "공지", "필독" 같은 중요한 메시지만 AI가 자동으로 추출해서 한눈에 보여주는 서비스.

## 문제
- 대학생, 직장인, 동아리 활동하는 누구나 겪는 문제
- 단톡방에 메시지 300개 넘게 쌓여있음
- 그 속에 "내일 조모임 3시", "과제 제출 기한 변경" 같은 중요 공지 묻힘
- 하나하나 읽기 귀찮아서 스크롤만 올렸다가 중요한 거 놓침
- 나중에 "어? 몰랐는데?" 하고 당황

## 해결 방식
1. 사용자가 단톡방 대화 내용 복사해서 붙여넣기 (또는 백업 파일 업로드)
2. AI가 텍스트 분석해서 중요한 메시지 자동 추출
3. "@전체", "공지", "일정", "과제", "필독" 같은 키워드 우선 필터링
4. 날짜/시간/장소 포함된 메시지 자동 분류
5. 정리된 리스트로 한눈에 확인

## 핵심 기능
- [ ] 텍스트 붙여넣기 또는 카톡 백업 파일 업로드
- [ ] LLM으로 중요 메시지 자동 추출
- [ ] 일정/과제/공지/기타로 카테고리 자동 분류
- [ ] 날짜/시간/장소 하이라이트 표시
- [ ] 추출 결과 텍스트/이미지로 저장

## 만들 수 있을까
- 필요한 기술/API: LLM (GPT-4 또는 Claude), 텍스트 파싱, 웹 프론트엔드
- 하루 안에 데모까지 갈 수 있는가: 텍스트 입력 + LLM 분석 + 결과 표시는 하루 안에 가능
- 걸림돌: 카카오톡 API 공식 지원 없어서 자동 크롤링 어려움 (수동 복붙으로 우회), LLM 비용

## 참고
- 비슷한 서비스: 없음 (카톡 요약 서비스는 있지만 공지 추출 특화 없음)
- 차별점: 단톡방 공지에 특화, 빠른 훑어보기
- MVP는 수동 복붙 방식으로 시작
