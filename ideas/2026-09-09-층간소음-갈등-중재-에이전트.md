# 층간소음 갈등 중재 에이전트

## 한 줄 요약
층간소음에 시달리지만 어떻게 대응할지 몰라 참거나 직접 항의하다 싸움이 되는 거주자를 위해, 소음을 기록하고 감정을 뺀 소통 문구를 만들고 공식 절차까지 단계별로 끌고 가는 에이전트.

## 문제
- 아파트·다세대 주택 거주자가 겪는 문제다.
- 지금은 두 가지로 버틴다. 그냥 참거나, 직접 찾아가거나 쪽지를 붙인다.
- 직접 대응은 확전으로 이어진다. 항의 쪽지에 위협으로 답하는 사례가 커뮤니티에서 화제가 되고, 층간소음 시비가 칼부림 같은 강력범죄로 번진 사건이 반복 보도됐다.
- 공식 절차가 있다는 건 알아도 어디서 시작해 어디로 가는지 모른다. 관리사무소, 층간소음 이웃사이센터, 환경분쟁조정위원회의 순서와 역할 구분이 일반인에게 불분명하다.
- 신고하려면 근거가 필요한데, 언제 어떤 소음이 얼마나 있었는지 개인이 체계적으로 남기기 어렵다. 기억에 의존한 항의는 "예민한 사람" 취급으로 되돌아온다.
- 인테리어 공사 소음은 갈등이 늘고 있는데 관련 법규조차 정비되지 않았다는 보도가 있다. 즉 제도로 덜 덮인 영역이다.

## 해결 방식
핵심은 **참는 것과 싸우는 것 사이의 빈칸**을 채우는 것이다. 감정을 대신 처리해주고, 근거를 쌓아주고, 절차를 대신 밟아준다.

1. 사용자가 소음을 겪을 때마다 기록한다. 버튼 한 번 또는 짧은 음성/텍스트로 남긴다.
2. 에이전트가 기록을 정리해 패턴을 찾는다. 시간대, 요일, 소음 유형, 지속 시간.
3. 사용자가 원하면 소통 문구를 만든다. 감정 표현과 비난을 걷어내고, 사실과 요청만 남긴 쪽지·문자 초안을 여러 톤으로 제시한다.
4. 상황이 안 풀리면 다음 단계 절차를 안내한다. 어디에, 무엇을 들고, 어떤 순서로 가는지.
5. 신고·조정 신청 시점에는 쌓인 기록을 증거 패키지로 묶는다. 타임라인 요약과 제출용 문서 초안까지.

## 핵심 기능
- [ ] 소음 발생 기록 (시각, 유형, 지속 시간, 메모)
- [ ] 기록 기반 패턴 요약 (시간대별·요일별 집계, 타임라인 뷰)
- [ ] 감정을 뺀 소통 문구 생성 (톤 여러 개 제시, 확전 위험 표현 걸러냄)
- [ ] 단계별 공식 절차 안내 (관리사무소 → 이웃사이센터 → 분쟁조정)
- [ ] 증거 패키지 자동 생성 (기록 요약 + 신청 문서 초안)
- [ ] 상대방 입장 시뮬레이션 (내 쪽지가 어떻게 읽힐지 미리 보여주기)
- [ ] 스마트폰 마이크 기반 소음 측정 보조

## 만들 수 있을까
- 필요한 기술/API: LLM (문구 생성·절차 안내·증거 요약), 로컬 DB 또는 간단한 백엔드 (기록 저장), 웹 오디오 API (측정 시도할 경우)
- 하루 안에 데모까지 갈 수 있는가: 기록 → 패턴 요약 → 문구 생성 → 증거 패키지 흐름은 하루 안에 가능해 보인다. 데모 시연 장면도 명확하다.
- 걸림돌
  - 스마트폰 마이크 데시벨 측정은 기기별 편차가 커서 법적 증거로서의 효력은 기대하기 어렵다. **확인 못 함** — 보조 기록으로만 쓰는 편이 안전하다.
  - 공식 절차의 최신 기준과 관할을 정확히 반영해야 한다. 틀린 절차 안내는 사용자에게 실제 손해를 준다. 출처를 함께 보여주는 방식이 필요하다.
  - 법률 자문으로 오해되지 않게 범위를 분명히 해야 한다.
