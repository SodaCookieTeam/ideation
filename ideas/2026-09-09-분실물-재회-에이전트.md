# 다시찾AI: 분실물 재회 에이전트

## 한 줄 요약
분실자가 물건 사진·분실 시간·동선을 입력하면 여러 모의 분실물 채널을 반복 탐색하고 일치 근거가 있는 후보와 안전한 문의 절차를 제시하는 에이전트다.

## 문제
- 분실자는 교내 게시판, 경비실, 커뮤니티 등 흩어진 채널을 직접 반복 확인해야 해 중요한 신규 등록을 놓치기 쉽다.
- 등록 글마다 사진, 표현, 위치, 시간이 달라 같은 물건인지 비교하는 데 시간이 오래 걸린다.
- 현재는 여러 채널을 검색하고 보관처에 일일이 문의하며 버티지만, 확인 피로와 늦은 대응 때문에 재회 가능성이 낮아진다.
- 후보를 성급하게 공개하거나 자동으로 수령 절차를 진행하면 타인의 물건을 가로채는 데 악용될 수 있다.
- 실제 외부 분실물 채널의 검색·알림·문의 API 제공 여부와 이용 조건은 확인 못 함.

## 해결 방식
사진·분실 시간·예상 동선을 구조화한 뒤 모의 채널의 등록 건을 이미지·텍스트·거리·시간 기준으로 비교하고, 점수와 근거를 함께 제시한다.

### 에이전트 루프
1. 사용자가 사진, 물건 특징, 분실 추정 시간, 이동 동선, 연락 선호 방식을 입력한다.
2. 에이전트가 모의 게시판·경비실·커뮤니티 채널을 탐색하고 등록 형식을 공통 스키마로 정규화한다.
3. 이미지 유사도, 특징 텍스트 일치도, 동선과 발견 위치의 거리, 분실과 발견 사이 시간을 각각 계산한다.
4. 가정한 가중치로 종합 일치도를 계산하고 일치·불일치 근거와 불확실성을 후보별로 설명한다.
5. 사용자가 후보를 선택하면 공개되지 않은 특징을 묻는 소유 확인 질문에 답하고 문의 발송을 승인한다.
6. 에이전트가 답변을 포함한 보관처 문의 메시지 발송을 모의 실행하며 실제 수령 전 보관처 본인확인이 필요함을 표시한다.
7. 미발견 상태라면 새 모의 등록 건을 주기적으로 재검색하고 임계값을 넘는 후보만 다시 알린다.

### 소유 확인과 안전장치
- 후보 화면에는 정확한 보관 위치와 등록자가 숨긴 식별 특징을 노출하지 않는다.
- 소유 확인 질문은 색상처럼 사진에서 바로 보이는 정보보다 흠집, 내용물, 잠금화면 등 비공개 특징을 우선 사용한다.
- 소유 확인 답변은 일치도 참고 자료일 뿐 소유권 증명이 아니며, 최종 전달은 보관처의 신분·소유 확인 절차를 거쳐야 한다.
- 문의는 사용자 승인 후에만 모의 발송하고 후보별 문의 횟수와 재시도 간격을 제한한다.
- 입력 사진, 동선, 답변은 데모 세션 종료 시 삭제하는 것으로 가정하고 화면에 삭제 상태를 표시한다.

## 핵심 기능
- [ ] 사진·분실 시간·동선·비공개 특징 입력과 검색 조건 생성
- [ ] 여러 모의 채널의 등록 건 수집·정규화와 주기적 재검색
- [ ] 이미지·텍스트·거리·시간의 개별 점수 및 가중 종합 점수 계산
- [ ] 후보 순위, 일치·불일치 근거, 불확실성 표시
- [ ] 소유 확인 질문과 보관처 본인확인 안내
- [ ] 사용자 승인 후 보관처 문의 메시지 발송 모의 실행
- [ ] 신규 등록 후보 알림과 중복·저신뢰 알림 억제

### 3분 데모
1. 0:00~0:30에 사용자가 검은색 이어폰 사진, 분실 시간, 캠퍼스 이동 동선을 입력한다.
2. 0:30~1:15에 에이전트가 세 모의 채널을 탐색하고 이미지·텍스트·거리·시간 점수를 계산하는 과정을 보여준다.
3. 1:15~1:50에 상위 후보 두 건을 근거와 함께 비교하고 낮은 후보의 불일치 이유도 보여준다.
4. 1:50~2:25에 사용자가 비공개 특징 질문에 답하고 문의 메시지를 검토한 뒤 발송을 승인한다.
5. 2:25~3:00에 모의 발송 결과와 보관처 본인확인 안내를 표시하고, 새 등록 건 재검색으로 더 높은 후보가 알림에 나타나는 장면을 보여준다.

## 만들 수 있을까
결론은 모의 데이터와 로컬 검색으로 하루 안에 핵심 루프를 시연할 수 있지만 실제 채널 연동과 신뢰할 수 있는 소유권 검증은 후속 검증이 필요하다는 것이다.

### 하루 MVP
- 사전에 준비한 JSON 모의 채널 세 개와 신규 등록 이벤트를 사용한다.
- 이미지 임베딩 또는 단순 특징 벡터, 키워드 유사도, 좌표 거리, 시간 차이를 계산해 설명 가능한 규칙 기반 점수를 만든다.
- 입력 화면, 후보 근거 카드, 소유 확인 질문, 승인 화면, 모의 문의 로그, 재검색 알림을 하나의 웹 데모로 연결한다.
- 이미지 모델의 정확도와 적절한 점수 가중치는 확인 못 했으므로 데모용 기준이라고 명시한다.

### 후속 확장
- 이용 허가를 받은 실제 채널 커넥터와 채널별 데이터 갱신 주기를 추가한다.
- 사용자 피드백과 실제 재회 결과로 채널별·물품별 가중치와 임계값을 보정한다.
- 보관처용 소유 확인 체크리스트, 만료 정책, 감사 로그, 다국어·접근성 입력을 추가한다.

### 제외 범위
- 실제 외부 채널 크롤링, API 연동, 메시지 발송, 자동 수령 예약은 하루 MVP에서 제외한다.
- 얼굴 인식, 사람 추적, 위치 동선의 제3자 공유는 제외한다.
- 에이전트가 소유권을 확정하거나 보관처 확인 없이 전달을 승인하는 기능은 제외한다.

### 리스크와 대응
- 유사 물건의 오탐은 개별 점수와 불일치 근거를 공개하고 사람의 최종 판단을 요구해 줄인다.
- 위치·시간·사진의 개인정보 노출은 최소 수집, 세션 삭제, 정확한 위치 지연 공개로 줄인다.
- 악의적 소유 주장은 비공개 특징 질문, 문의 속도 제한, 보관처 본인확인으로 억제한다.
- 반복 알림 피로는 중복 제거, 신뢰도 임계값, 알림 중지 기능으로 줄인다.
- 실제 채널의 약관, API, 데이터 사용 허용 범위는 확인 못 했으며 연동 전 별도 검토가 필요하다.

## 참고
- 실제 외부 분실물 채널 API와 메시지 발송 수단은 확인 못 함.
- 데모의 채널 데이터, 점수 가중치, 재검색 주기는 모두 가정이다.
- 실제 운영 전 개인정보 보관 기간, 소유권 분쟁 절차, 보관처 신원 확인 정책을 확인해야 한다.
