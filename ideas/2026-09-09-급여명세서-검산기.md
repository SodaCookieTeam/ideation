# 급여명세서 검산기

## 한 줄 요약
알바 급여가 맞는지 검증할 방법이 없어 그냥 받는 학생을 위해, 명세서를 올리면 주휴수당과 가산수당을 다시 계산해 덜 받은 금액을 근거와 함께 찾아준다.

## 문제
- 시급제 알바를 하는 대학생
- 입금액이 맞는지 확인할 방법이 없다. 계산기 앱에 숫자를 넣어보다 규정이 헷갈려 포기한다.
- 주휴수당이 아예 빠져 있어도 그게 빠진 것인지 모른다.
- 사장에게 물어볼 근거가 없어서 말을 못 꺼낸다.

## 해결 방식
1. 명세서 이미지·PDF와 근무기록을 입력받아 항목 추출
2. 최저임금·주휴수당·야간/연장 가산·공제를 **코드로** 재계산해 차액 산출 (LLM에 산술을 맡기지 않는다)
3. 차액이 있으면 사장에게 보낼 정중한 확인 요청 메시지 생성

## 핵심 기능
- [ ] 명세서 파싱 → 항목 추출 (최소 기능)
- [ ] 코드 기반 재계산과 항목별 일치/불일치 표시
- [ ] 불일치 항목의 계산 근거 펼쳐보기
- [ ] 확인 요청 메시지 초안

## 만들 수 있을까
- 필요한 기술: OCR 또는 PDF 파싱, 계산 로직은 순수 함수로 구현, LLM은 항목 매핑과 설명 생성만
- 하루 안에 데모까지: **가능.** 계산 규칙이 명확하고 입력이 사용자 제공 파일이다. 숫자 신뢰도를 코드로 확보하는 설계라 심사 질문에도 버틴다.
- 최저임금과 수당 기준값은 고시된 값을 상수로 넣는다. **연도별 최신 수치는 반드시 확인하고 넣어야 하며 지금은 확인 못 함.**
- 걸림돌
  - 근무기록 입력이 번거로워 데모 흐름이 늘어질 수 있다. 샘플 근무표를 프리셋으로 준비한다.
  - 감시·단속적 근로 등 수당 규정 예외는 범위 밖으로 명시한다.

## 시연 장면
명세서 이미지를 올리면 항목마다 초록 체크가 순서대로 찍히다가 '주휴수당' 칸에서 빨간 X가 뜬다. 옆에 "예상 62,400원 / 지급 0원, 근거: 1주 15시간 이상 근무" 계산 과정이 펼쳐지고, 아래에 문의 메시지가 완성된다.

## 참고
- 알바몬 시급 계산기 등은 사용자가 숫자를 직접 넣는 계산기다.
- 이 아이디어는 실제 명세서 문서를 읽어 대조하고, 어긋난 지점의 근거까지 붙인다. 문서 작성이 목적이 아니라 **검산**이 목적이다.
- 인접 아이디어: 계약 조항 3자 대립 검토실(서명 전 단계). 이 문서는 급여 지급 후 단계라 역할이 다르다.
