# 재난문자 행동 번역 에이전트

## 한 줄 요약
재난문자를 받아도 뭘 해야 할지 몰라 그냥 넘기는 문제를, 문자 원문을 내 상황에 맞는 "지금 할 일"로 바꿔 해결한다.

## 문제
- 전 국민. 특히 반지하 거주자, 고층 거주자, 유아 동반 보호자, 이동 약자
- 재난문자는 "○○동 침수 우려, 안전에 유의하세요" 수준이라 행동 지시가 없다.
- 반려동물이 있는 사람, 지하 주차장에 차를 둔 사람, 고령 부모와 사는 사람의 할 일이 전부 다른데 문자는 하나다.
- 지금은 각자 검색하거나 무시한다.

## 해결 방식
1. 재난문자 원문을 붙여넣거나 스크린샷으로 입력 → 재난 종류·심각도·요구 행동 파싱
2. 사전에 설정한 프로필(주거 형태, 층수, 동반 가족, 이동 능력, 차량 보유) 기준으로 행동 카드 생성 — 지금 / 1시간 내 / 대피 시
3. 각 항목에 공식 국민행동요령의 근거를 붙인다. 지침에 없는 내용은 **"지침 밖 추정"으로 구분 표시**한다
4. "지금 하지 말아야 할 것"(예: 지하 진입)을 함께 경고한다

## 핵심 기능
- [ ] 문자 입력 → 재난 종류·요구 행동 파싱 (최소 기능)
- [ ] 프로필 기준 행동 카드 3단(지금 / 1시간 내 / 대피 시)
- [ ] 근거 지침 인용과 지침 밖 추정 구분 표시
- [ ] 금지 행동 경고

## 만들 수 있을까
- 필요한 기술: LLM, 국민재난안전포털의 재난별 국민행동요령 텍스트, 임베딩 검색
- 하루 안에 데모까지: **가능.** 텍스트 입력 + 프로필 + 지침 문서 검색으로 끝난다. 기상 원자료나 위성 처리는 하지 않는다.
- 재난문자 실시간 수신 API의 존재와 이용 조건은 **확인 못 함.** 붙여넣기 입력을 기본 경로로 설계하고 실시간 연동은 범위에서 뺀다.
- 걸림돌
  - **안전 관련 조언이라 틀리면 위험하다.** 반드시 공식 행동요령 문서에 근거를 붙이고, 근거 없는 항목은 생성하지 않도록 프롬프트를 제약한다. 이 작업에 시간을 써야 해서 UI가 얇아진다.
  - 대피소 좌표 데이터를 못 구하면 지도 장면이 비어 보인다. 지도는 선택 기능으로 두고 행동 카드에 집중한다.

## 시연 장면
실제로 받았던 폭우 재난문자를 그대로 붙여넣는다. 프로필을 "반지하·혼자"로 두면 "지금 현관 쪽 물 유입 확인 / 정전 대비 / 지하 진입 금지"가 뜬다. 프로필을 **"아파트 12층·유아 동반"으로 바꾸면 완전히 다른 카드가 나온다.** 같은 문자, 다른 지시.

## 참고
- 안전디딤돌 앱은 문자 열람과 지침 문서 링크 제공에서 멈춘다. 개인 조건별로 행동을 재작성하는 기능은 없다.
- 공공성이 강해 주제가 사회문제·재난·공공서비스 계열로 나올 때 가장 잘 붙는 후보다.
