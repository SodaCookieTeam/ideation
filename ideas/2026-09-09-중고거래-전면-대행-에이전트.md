# 감정 소모 방지: 중고거래 전면 대행 에이전트

## 한 줄 요약
물건 사진만 올리면 AI가 시세 분석·판매 글 작성·가격 협상·일정 연동까지 중고 거래 전 과정을 대신 처리해주는 에이전트.

## 문제
- 중고 물건을 팔고 싶은 누구나 겪는 문제
- 시세 검색, 판매 글 작성에 시간이 걸림
- "얼마에 팔아요?" 찔러보기 응대가 귀찮고 감정 소모가 큼
- 가격 협상 과정에서 스트레스 발생
- 거래 약속 잡는 것도 번거로움

## 해결 방식
1. 사용자가 판매할 물건 사진 업로드
2. Vision AI가 물건 상태와 적정 시세 분석
3. 매력적인 판매 글 자동 작성 및 플랫폼 등록
4. 구매자 채팅이 오면 AI가 사전 설정된 최하한선 내에서 가격 협상 대행
5. 거래 성사 시 약속 시간·장소를 캘린더에 자동 연동

## 핵심 기능
- [ ] 사진 업로드 → Vision AI 상태 분석 및 시세 산출
- [ ] 판매 글 자동 작성
- [ ] 구매자 채팅 자동 응대 및 가격 협상 대행 (최하한선 기준)
- [ ] 거래 성사 시 캘린더 자동 연동

## 만들 수 있을까
- 필요한 기술/API: Vision AI(GPT-4o Vision 등), LLM(채팅 대행), 중고 플랫폼 API(당근마켓 등), Google Calendar API
- 하루 안에 데모까지 갈 수 있는가: 사진 분석 + 판매 글 생성 + 협상 시뮬레이션까지는 하루 안에 가능
- 걸림돌: 당근마켓 등 플랫폼 공식 API 미제공, 실제 채팅 자동화 구현 난이도

## 참고
- 비슷한 서비스: 없음 (차별점 있음)
- 당근마켓, 번개장터 등 중고 플랫폼 참고
