# 청년/시민 맞춤형 숨은 지원금 헌터 (정책 에이전트)

## 한 줄 요약
청년/시민이 자신의 프로필을 입력하면 AI 에이전트가 매일 공공기관 지원금을 크롤링해 맞춤 알림을 주고 신청서 초안까지 자동으로 작성해주는 서비스.

## 문제
- 청년, 사회초년생, 일반 시민이 겪는 문제
- 서울시·자치구·국가에서 주는 지원금(주거, 취업, 생활 등)이 많지만 공고를 매번 챙겨보기 어려움
- 조건이 복잡해서 본인이 해당되는지 파악하기 힘듦
- 신청서 작성이 번거롭고 어디서 신청하는지도 모르는 경우가 많음

## 해결 방식
1. 사용자가 기본 프로필(나이, 거주지, 소득 분위, 관심사) 입력
2. AI 에이전트가 매일 공공기관 웹사이트를 크롤링
3. 조건에 맞는 지원 사업 발견 시 알림 발송
4. 사용자의 기존 프로필 정보를 바탕으로 신청서 초안 자동 생성

## 핵심 기능
- [ ] 사용자 프로필 입력 및 저장 (나이, 거주지, 소득 분위, 관심사)
- [ ] 공공기관 지원금 공고 크롤링 (서울시, 자치구, 중앙부처)
- [ ] 조건 매칭 및 맞춤 알림
- [ ] 신청서 초안 자동 작성

## 만들 수 있을까
- 필요한 기술/API: 웹 크롤링(Playwright/BeautifulSoup), LLM(신청서 초안 생성), 알림(이메일/푸시)
- 하루 안에 데모까지 갈 수 있는가: 크롤링 대상 사이트를 2~3개로 좁히면 가능
- 걸림돌: 공공기관 사이트마다 구조가 달라 크롤러 유지보수 부담, 개인정보 처리

## 참고
- 주최 측(서울시/국민대 캠퍼스타운) 성격과 잘 맞는 아이디어
- 복지로(bokjiro.go.kr), 서울시 복지포털 등 참고
