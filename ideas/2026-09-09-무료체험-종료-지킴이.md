# 무료체험 종료 지킴이

## 한 줄 요약
무료체험을 자주 신청하는 사용자가 가입 안내 캡처나 이메일을 올리면, AI가 유료 전환 조건과 종료 시점을 원문 근거와 함께 확인하고 사용자 승인 후 알림과 해지 체크리스트를 만들어 주는 에이전트.

## 문제

### 누가 겪는 문제인가

- 영상·음악·생산성 앱 등 여러 구독 서비스를 시험해 보는 사람
- 무료체험은 필요하지만 유료 전환을 계속 이용할지는 나중에 결정하고 싶은 사람
- 서로 다른 서비스의 종료일과 해지 경로를 따로 기억하기 어려운 사람

### 지금은 어떻게 버티고 있는가

- 가입 직후 종료일을 캘린더에 직접 입력한다.
- 결제 예정 이메일이나 가입 화면을 캡처해 두고 나중에 다시 찾는다.
- 카드 명세서에 결제가 나타난 뒤에야 구독 사실을 떠올린다.

### 왜 불편한가

- 서비스마다 체험 기간, 유료 전환 시각, 결제 주기, 해지 경로가 다르다.
- 캡처만 해두면 중요한 날짜와 금액이 다른 이미지 속에 묻힌다.
- 앱을 삭제하는 것과 구독 해지는 다르다. Google Play도 앱 삭제만으로는 구독이 취소되지 않는다고 안내한다.
- 날짜를 잘못 읽거나 시간대를 놓치면 원하지 않는 결제로 이어질 수 있다.

## 해결 방식

사용자가 가입 안내 캡처, 결제 예정 이메일 또는 PDF를 직접 올리면 에이전트가 다음 순서로 처리한다.

### 에이전트 루프

1. **관찰**: 이미지나 문서에서 서비스명, 무료체험 종료일, 유료 전환 금액, 결제 주기, 해지 관련 문구를 찾는다.
2. **판단**: 추출한 정보를 `서비스명 / 종료 시각 / 결제 금액 / 결제 주기 / 해지 경로 / 근거 문장 / 신뢰도`로 구조화한다.
3. **사용자 확인**: 원문 근거를 강조해서 보여주고, 날짜·시간대·금액이 빠졌거나 서로 충돌하면 추측하지 않고 한 번에 필요한 질문을 한다.
4. **실행**: 사용자가 내용을 승인하면 D-3과 D-1 알림이 담긴 `.ics` 파일과 서비스별 해지 체크리스트를 만든다.
5. **재계획**: 사용자가 날짜를 수정하거나 새 안내문을 추가하면 기존 계획과의 차이를 보여주고 알림 파일을 다시 만든다. 사용자가 해지 완료로 표시하면 결제 전 최종 확인 항목으로 바꾼다.

### 90초 데모 시나리오

1. `9월 12일 23:59 무료체험 종료, 이후 월 14,900원`이라고 적힌 가상의 스트리밍 서비스 가입 화면을 업로드한다.
2. 에이전트가 종료일, 금액, 결제 주기와 각 항목의 원문 근거를 행동 카드로 보여준다.
3. 시간대가 문서에 없기 때문에 에이전트가 사용자에게 한국 시간 기준인지 묻는다.
4. 사용자가 확인하면 D-3·D-1 알림이 포함된 `.ics` 파일과 해지 체크리스트를 생성한다.
5. 사용자가 종료일을 하루 앞당겨 수정하면 변경 이유를 표시하고 새 알림 파일을 만든다.

데모는 사용자가 **근거 확인 → 정보 승인 → 캘린더 파일 다운로드 → 해지 절차 확인**까지 완료하면 성공이다.

### 안전장치

- 원문에 없는 종료 시각이나 금액은 생성하지 않고 `확인 필요`로 표시한다.
- 외부 캘린더 등록이나 해지와 같은 행동은 사용자의 명시적 승인 뒤에만 준비한다.
- 업로드한 문서는 데모 세션 동안만 사용하고 기본값으로 저장하지 않는다.
- 에이전트가 만든 체크리스트는 해지를 보장하지 않는다. 사용자가 서비스의 최종 해지 화면이나 확인 이메일을 직접 확인하도록 안내한다.

## 핵심 기능

### 하루 MVP

- [ ] 이미지·PDF·이메일 본문 텍스트 수동 업로드
- [ ] 멀티모달 모델을 이용한 종료일·결제금액·결제주기 구조화
- [ ] 추출값마다 원문 근거와 신뢰도 표시
- [ ] 누락되거나 충돌하는 정보에 대한 확인 질문
- [ ] 사용자 승인 후 D-3·D-1 알림이 담긴 `.ics` 파일 생성
- [ ] Google Play 데모 사례의 공식 해지 링크와 단계별 체크리스트 제공
- [ ] 사용자 수정 내용을 반영한 행동 카드와 알림 재생성
- [ ] 외부 모델 호출이 실패할 때 번들 샘플 문서와 샘플 추출 결과로 데모 지속

### 후속 확장

- [ ] 이메일 받은편지함에서 사용자가 선택한 가입 안내만 가져오기
- [ ] 여러 무료체험과 정기 구독을 한 화면에서 관리하기
- [ ] 가격이나 약관 변경 안내가 들어오면 기존 계획과 비교하기
- [ ] 해지 완료 화면이나 확인 이메일을 읽어 상태 갱신하기
- [ ] Google Calendar 등과 동기화해 알림 변경 사항을 자동 반영하기

### 이번 데모에서 제외

- 이메일 계정이나 금융 계좌의 상시 연결
- 카드 명세서 전체 분석
- 사용자 승인 없는 자동 해지, 전화, 결제 또는 환불 요청
- 모든 서비스의 최신 약관을 자체적으로 보장하는 기능

## 만들 수 있을까

### 필요한 기술/API

- 이미지와 문서를 이해하고 정해진 필드로 반환할 수 있는 멀티모달 LLM
- 추출값, 원문 근거, 신뢰도를 함께 보여주는 간단한 웹 UI
- iCalendar 이벤트 생성기. Google Calendar는 컴퓨터에서 `.ics` 파일 가져오기를 지원한다.
- 데모용 Google Play 해지 안내 링크와 소규모 서비스 메타데이터

별도 데이터베이스와 캘린더 OAuth 없이도 파일 업로드부터 알림 다운로드까지 보여줄 수 있다.

### 하루 구현 범위

1. 업로드 화면과 번들 샘플 문서 준비: 1시간
2. 구조화 추출 프롬프트·스키마와 샘플 결과 구현: 2시간
3. 원문 근거 확인·수정 UI 구현: 1시간 30분
4. `.ics` 생성과 해지 체크리스트 연결: 1시간 30분
5. 실패 대체 흐름, 데모 리허설, 화면 정리: 1시간

### 걸림돌과 대응

| 걸림돌 | 대응 |
| --- | --- |
| 날짜 표기와 시간대가 모호함 | 근거 문장과 신뢰도를 표시하고 사용자가 확정하기 전에는 알림을 만들지 않는다. |
| 서비스마다 해지 경로와 정책이 다름 | MVP는 Google Play 사례 하나만 완전하게 지원하고 나머지는 원문 링크를 안내한다. |
| 민감한 이메일·결제 정보가 포함될 수 있음 | 업로드 파일을 기본 저장하지 않고 데모용 가상 문서를 사용한다. |
| 모델이나 네트워크 호출 실패 | 동일한 샘플 문서에 대한 번들 추출 결과로 전체 데모를 진행한다. |
| 알림만 만들고 실제 해지가 안 될 수 있음 | 마지막 상태를 `해지 확인 필요`로 두고 최종 확인 증거를 요구한다. |

## 참고

### 공식 문서·정책

- [Google Play 구독 취소 안내](https://support.google.com/googleplay/answer/7018481) — 앱 삭제만으로 구독이 취소되지 않으며 구독 관리 화면에서 직접 취소해야 한다.
- [Google Play 구독 및 무료체험 정책](https://support.google.com/googleplay/android-developer/answer/9900533) — 무료체험 기간, 유료 전환 시점·금액, 취소 방법을 사용자에게 명확히 안내하도록 요구한다.
- [Google Calendar에 일정 가져오기](https://support.google.com/calendar/answer/37118) — 컴퓨터에서 `.ics`와 CSV 파일을 가져오는 방법과 iCalendar 기본 형식을 설명한다.
- [RFC 5545: iCalendar](https://www.rfc-editor.org/rfc/rfc5545.html) — `.ics` 파일이 따르는 표준 명세.

### 유사 서비스

- [Rocket Money 구독 취소 안내](https://help.rocketmoney.com/en/articles/934402-how-do-i-cancel-a-subscription-on-rocket-money) — 구독 목록에서 취소를 요청하거나 직접 취소 방법을 확인할 수 있다.
- [Bobby](https://www.bobbyapp.co/) — 사용자가 구독과 반복 비용을 직접 등록하고 추적하는 서비스.

이 아이디어는 금융 계정에서 이미 발생한 반복 결제를 찾기보다, **가입 안내문 자체를 입력으로 삼아 첫 결제 전에 행동 계획을 만든다**는 점에 집중한다.
