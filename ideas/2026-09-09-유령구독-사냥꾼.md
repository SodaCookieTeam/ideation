# 유령 구독 사냥꾼

## 한 줄 요약
무료 체험 후 자동 결제로 넘어간 구독을 몇 달째 모르고 내는 문제를, 결제 문자를 붙여넣기만 하면 유령 구독을 찾아내고 해지 문서까지 만들어 해결한다.

## 문제
- 20대, 앱과 클라우드 구독이 많은 사용자
- 카드 명세서를 눈으로 훑어야 알 수 있고, 보통은 결제되고 나서야 알아차린다.
- 발견해도 해지 버튼이 어디 있는지 찾는 것 자체가 미로라서 미루다 한 달 더 낸다.
- 오픈뱅킹이나 마이데이터로 계좌를 연동하는 방식은 인증 절차 때문에 하루 안에 못 만든다. 그래서 처음부터 **붙여넣기 입력**으로 우회한다.

## 해결 방식
1. 결제 문자와 영수증 메일 텍스트를 대량으로 붙여넣기 → 서비스명·주기·금액 정규화
2. 6개월 이상 결제되었는데 사용 흔적 질문에 "안 쓴다"로 답한 항목을 유령 구독으로 분류하고 누적 손실 환산
3. 서비스별 해지 경로 안내와 해지 요청 메일 문구 초안 생성

## 핵심 기능
- [ ] 문자 대량 붙여넣기 → 구독 목록 구조화 (최소 기능)
- [ ] 유령 구독 분류와 누적 금액 환산
- [ ] 해지 요청 문구 자동 생성
- [ ] 해지 경로 정보에 "확인 필요" 라벨 표시

## 만들 수 있을까
- 필요한 기술: LLM 구조화 출력(JSON 스키마 강제), 웹 프런트, 로컬 DB
- 하루 안에 데모까지: **가능.** 인증 절차가 없고 파싱·분류·문서 생성이 모두 한 파이프라인이다. 이 목록에서 가장 안전한 후보 중 하나다.
- 걸림돌
  - 통신사·카드사별 문자 포맷이 제각각이라 파싱 실패 케이스가 나온다. 데모용 샘플 세트를 미리 확보한다.
  - 해지 경로 정보가 틀릴 수 있으므로 단정하지 않고 "확인 필요"를 붙인다.

## 시연 장면
심사위원 앞에서 실제 결제 문자 40건을 통째로 붙여넣는다. 3초 뒤 화면에 구독 카드들이 우르르 쌓이고, 그중 3개가 붉게 흔들리며 "11개월째 결제, 마지막 사용 기억 없음 / 누적 87,000원"으로 뜬다. 하나를 클릭하면 해지 요청 메일이 이미 작성된 상태로 열린다.

## 참고
- 뱅크샐러드, 토스의 구독 관리는 계좌 연동으로 목록만 보여준다.
- 이 아이디어는 연동 없이 텍스트만으로 동작하고, 목록이 아니라 **해지 실행 문서**까지 만든다.
