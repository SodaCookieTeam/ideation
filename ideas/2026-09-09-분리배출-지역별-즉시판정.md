# 지역별 분리배출 즉시 판정기

## 한 줄 요약
이사한 자취생이 "이건 여기서 어떻게 버리나"를 몰라 감으로 버리는 문제를, 쓰레기 사진 한 장과 지역 선택으로 그 동네 기준 판정을 주어 해결한다.

## 문제
- 자취생, 신혼, 이사 직후 1인 가구
- 같은 품목도 지자체마다 규칙이 다르다. 종이팩 별도 배출, 투명 페트 분리, 스티로폼 취급, 아이스팩 처리가 지역마다 갈린다.
- 지금은 검색을 두세 번 하다 포기하고 감으로 버린다. 틀리면 과태료나 미수거로 돌아온다.

## 해결 방식
1. 쓰레기 사진 촬영 → Vision 모델이 품목·재질·오염 여부 판정
2. 사용자가 고른 지역의 배출 규칙 문서를 근거로 붙여 "이 동네 기준" 답변 생성
3. 애매한 항목은 결론을 단정하지 않고 "왜 애매한지 + 두 선택지의 결과"를 같이 제시
4. 배출 요일·배출 방식을 요약 카드로 출력

## 핵심 기능
- [ ] 사진 → 품목·재질 판정 (최소 기능)
- [ ] 지역 선택에 따라 판정이 달라지는 규칙 대조
- [ ] 애매 항목의 근거 표시와 배출 요약 카드
- [ ] 판정 근거가 된 규칙 원문 인용

## 만들 수 있을까
- 필요한 기술: 멀티모달 LLM(이미지 입력), 지자체 배출 안내 문서 텍스트, 임베딩 검색
- 하루 안에 데모까지: **가능.** 모델 학습이 없고, 사진 한 장을 Vision 모델에 넣고 미리 수집한 규칙 문서로 근거를 붙이는 구조다.
- 환경부나 지자체가 표준 배출 규칙 API를 제공하는지는 **확인 못 함.** 데모는 2~3개 지역 안내 문서를 미리 수동 수집하는 전제로 설계한다.
- 걸림돌
  - 오염된 쓰레기 사진의 재질 판정이 흔들린다. 현장 조명이 나쁠 때를 대비해 촬영본을 미리 준비해야 한다.
  - 규칙 문서 수집 범위를 욕심내면 오전이 다 간다. 2곳으로 고정한다.

## 시연 장면
심사위원 앞 테이블의 실제 쓰레기(라면 봉지, 아이스팩, 영수증, 택배 비닐)를 한 장씩 찍는다. "성북구"로 두면 각각 판정 카드가 뜬다. 지역을 "세종시"로 바꾸는 순간 **같은 사진의 판정이 뒤집힌다.** 토글 하나로 결론이 달라지는 것이 이 데모의 핵심이다.

## 참고
- 기존 서비스: 내 손안의 분리배출, 각 지자체 앱 — 품목 검색 사전이거나 안내문 링크 제공에 그친다.
- 지역 규칙 차이를 같은 사진에 겹쳐 결론을 바꿔주는 형태는 확인되지 않았다.
