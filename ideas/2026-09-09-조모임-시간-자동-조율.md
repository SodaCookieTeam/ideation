# 조모임 시간 자동 조율 도구

## 한 줄 요약
팀플/조모임 시간 정하느라 단톡방에서 "나 X시 안 돼" 무한 반복하지 말고, 각자 불가능한 시간만 체크하면 모두가 가능한 시간을 자동으로 찾아주는 서비스.

## 문제
- 대학생 팀플, 동아리 모임을 잡는 누구나 겪는 문제
- 단톡방에서 "다들 언제 돼?" 물어보면 각자 다른 시간에 답장
- "나 월수금 안 돼", "나 화목 오전만 돼" 정보가 뒤섞임
- 손으로 일일이 겹쳐서 계산하기 어려움
- 결국 모두가 불편한 시간에 억지로 맞추거나, 정하는 데만 하루 이틀 걸림

## 해결 방식
1. 방장이 "조모임 시간 정하기" 링크 생성 및 공유
2. 조원들이 링크 클릭해서 이름 입력 + 불가능한 시간 체크 (주간 시간표 형식)
3. 모두가 제출하면 시스템이 교집합 자동 계산
4. "목요일 오후 3시가 유일" 같은 결과 즉시 표시
5. 결과를 단톡방에 이미지로 공유

## 핵심 기능
- [ ] 링크 생성 및 공유 (방장)
- [ ] 주간 시간표 UI에서 불가능 시간 클릭으로 체크
- [ ] 실시간 참여 현황 표시 (5명 중 3명 제출 완료)
- [ ] 모두가 가능한 시간대 자동 계산 및 표시
- [ ] 결과 이미지 다운로드 및 카톡 공유

## 만들 수 있을까
- 필요한 기술/API: React (시간표 UI), Node.js + DB (시간 데이터 저장), 시간대 교집합 알고리즘
- 하루 안에 데모까지 갈 수 있는가: 시간표 UI + 데이터 저장 + 교집합 계산은 하루 안에 가능
- 걸림돌: 모바일 UI 최적화 시간 소요, 많은 인원 (10명 이상) 시 계산 복잡도

## 참고
- 비슷한 서비스: Doodle, When2meet (but UI 복잡하고 영어, 시간대 일일이 클릭 방식 불편)
- 차별점: "불가능 시간"만 체크하는 방식으로 더 빠름, 한국어, 모바일 최적화, 카톡 공유 최적화
- 대학생 팀플에 최적화된 UX
