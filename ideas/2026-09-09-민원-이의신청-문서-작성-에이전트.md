# 민원·이의신청·내용증명 문서 작성 에이전트

## 한 줄 요약
억울한 상황을 말로 설명하면 AI 에이전트가 형식에 맞는 민원·이의신청·내용증명 문서를 대신 작성해주는 서비스.

## 문제
- 카드사·통신사에 요금을 따지거나, 환불을 요구하거나, 보증금 반환을 청구해야 하는 일반 시민이 겪는 문제
- 지금은 인터넷에서 남의 양식을 찾아 복붙하거나, 어떻게 써야 할지 몰라 그냥 포기한다
- 형식과 법적 표현을 모르면 문서가 무시당하기 쉽고, 내용증명 같은 건 어디서부터 손대야 할지 막막하다
- 고유가 지원금 이의신청이 급증하는 등, 이의제기 자체는 자주 생기는데 문서 작성 문턱이 높다 (확인된 사실)

## 해결 방식
1. 사용자가 상황을 말이나 글로 설명하고, 관련 증빙(고지서·문자·계약서 사진)을 첨부한다
2. 에이전트가 상황 유형(요금 이의, 환불 요구, 보증금 반환, 국민신문고 민원 등)을 분류한다
3. 유형별 표준 형식에 맞춰 문서 초안을 작성한다 (내용증명은 발신인·수신인·요지·요구사항·근거 구조)
4. 사용자가 톤(정중/강경)과 세부 내용을 고르면 최종본과 발송 방법 안내까지 제공한다

## 핵심 기능
- [ ] 상황 설명 입력 → 문서 유형 자동 분류
- [ ] 유형별 표준 형식에 맞춘 문서 초안 자동 생성
- [ ] 톤 조절(정중/강경) 및 재작성
- [ ] 발송 방법 안내 (내용증명 우체국 접수, 국민신문고 제출 등)
- [ ] 증빙 사진에서 핵심 정보(금액·날짜·상대방) 추출

## 만들 수 있을까
- 필요한 기술/API: LLM(문서 생성·분류), OCR(증빙 정보 추출, 선택)
- 하루 안에 데모까지 갈 수 있는가: 순수 LLM 기반이라 상황 입력 → 문서 생성까지 핵심 흐름은 하루 안에 충분히 가능
- 걸림돌: 법적 정확성 보장은 어려움 (초안 보조 도구로 포지셔닝 필요), 문서 유형별 표준 형식 데이터 정리 필요

## 참고
- 국민신문고, 우체국 내용증명 서비스
- 검색으로 확인한 "이의신청 급증" 근거는 [dcinside issuefeed](https://issuefeed.dcinside.com/) 등에서 확인, 라이선스 준수 위해 재구성함
- 기존 아이디어와의 관계: 숨은 지원금 헌터(혜택 찾기), 중고거래 대행(거래 대행)과 도메인이 겹치지 않는 별개 주제
