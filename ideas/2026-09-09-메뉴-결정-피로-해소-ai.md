# 메뉴 결정 피로 해소 AI

## 한 줄 요약
매 끼니 메뉴 고민으로 시간을 낭비하는 사람들에게 AI가 식사 이력, 날씨, 기분, 동행인을 고려해 최적의 메뉴를 단 3초 안에 추천하는 서비스.

## 문제
- 직장인, 대학생, 1인 가구가 겪는 문제
- 하루 3번 "뭐 먹지" 고민에 시간과 에너지 소모
- 같은 메뉴 반복으로 식사 만족도 하락
- 여럿이 모였을 때 취향 조율이 어려움
- 날씨나 컨디션에 맞는 메뉴를 찾기 어려움

## 해결 방식
1. 사용자가 간단한 질문에 답변 (기분, 날씨, 동행인, 예산)
2. AI가 최근 식사 이력을 분석해 중복 방지
3. 날씨, 시간대, 위치를 고려한 메뉴 1개 확정 추천
4. 선택권을 주지 않고 단호하게 하나만 제시
5. 식사 후 만족도 입력으로 추천 정확도 개선

## 핵심 기능
- [ ] 간단한 질문 폼 (기분, 날씨, 동행인, 예산)
- [ ] 최근 식사 이력 추적 및 중복 방지
- [ ] LLM 기반 메뉴 추천 (단 1개만 제시)
- [ ] 위치 기반 식당 추천 연동
- [ ] 만족도 피드백 및 학습

## 만들 수 있을까
- 필요한 기술/API: LLM (GPT), LocalStorage/DB, Geolocation API, 날씨 API, 카카오맵/네이버맵 API
- 하루 안에 데모까지 갈 수 있는가: 질문 폼 + LLM 추천 + 이력 저장은 하루 안에 가능
- 걸림돌: 추천 정확도를 높이려면 데이터 축적 필요, 위치 기반 식당 연동은 선택 사항

## 참고
- 기존 서비스는 여러 옵션 제시하는데, 이 서비스는 "선택권을 주지 않음"이 차별점
- 결정 피로(Decision Fatigue) 해소가 핵심 가치
- 비슷한 서비스: 망고플레이트, 카카오맵 (but 선택지 과다 제공)
