# 외국인 정착 행정 순서 풀어주는 에이전트

## 한 줄 요약
한국에 막 도착한 외국인이 서로 얽힌 행정 절차(폰·계좌·외국인등록증·본인인증) 앞에서 막힐 때, 지금 당장 할 수 있는 다음 한 단계를 계산해서 순서대로 끌고 가는 에이전트.

## 문제
- 한국에 새로 온 외국인 거주자와 장기 체류자가 겪는 문제다.
- 절차들이 서로를 요구한다. 은행 계좌를 열려면 본인인증된 한국 휴대폰 번호가 필요한데, 후불 휴대폰을 개통하려면 보통 한국 은행 계좌가 필요하다. 전형적인 닭과 달걀 문제로 정리된 자료가 있다.
- 외국인등록증을 갓 받은 상태에서 핀테크 앱 본인인증이 첫 시도에 실패하는 경우가 많다. 토스, 카카오뱅크, 네이버페이에서 같은 실패를 겪는다는 정리가 있다.
- 지금은 이렇게 버틴다. 블로그와 레딧을 뒤지고, 먼저 온 사람에게 묻고, 은행이나 통신사 지점에 갔다가 서류가 없어 헛걸음한다.
- 정보가 없는 게 아니라 **순서와 조건이 흩어져 있다.** 개별 가이드는 많지만 "내 상황에서 지금 뭘 먼저 해야 하는지"를 알려주는 건 없다.
- 커뮤니티 규모로 봐도 수요가 크다. r/Living_in_Korea 는 13만 명 규모이고, 논의 유형이 대부분 조언 요청과 해결책 요청이며 struggling, frustrating 같은 표현이 자주 등장한다는 분석이 있다.
- 단기 체류자도 막힌다. 본인인증을 통과하지 못해 배달 앱 주문조차 못 한다는 불만이 여행자 커뮤니티에 반복된다.

## 해결 방식
핵심은 정보 나열이 아니라 **의존성 해결**이다. 절차 간 선후 관계를 그래프로 두고, 사용자의 현재 상태에서 실행 가능한 다음 단계를 계산한다.

1. 사용자 상태를 입력받는다. 비자 종류, 입국일, 외국인등록증 발급 여부, 보유 통신 수단, 계좌 유무, 체류 예정 기간.
2. 에이전트가 의존성 그래프를 풀어 **지금 바로 가능한 단계**만 골라낸다. 아직 조건이 안 된 단계는 왜 막혀 있는지 함께 보여준다.
3. 각 단계마다 준비물 체크리스트를 만든다. 헛걸음을 없애는 것이 목표다.
4. 막힌 지점에는 우회 경로를 제시한다. 예를 들어 선불 유심으로 번호를 먼저 확보한 뒤 후불로 전환하는 경로.
5. 진행 상황을 기억한다. 한 단계를 끝내면 그래프를 다시 풀어 다음 단계를 갱신한다.
6. 기관 방문이 필요하면 위치, 영업시간, 외국어 지원 여부를 함께 붙인다.

## 핵심 기능
- [ ] 상태 입력 대화 (비자·등록증·통신·계좌 현황 파악)
- [ ] 의존성 그래프 기반 다음 단계 계산 (막힌 이유 설명 포함)
- [ ] 단계별 준비물 체크리스트
- [ ] 막힌 지점 우회 경로 제안
- [ ] 진행 상황 추적 및 다음 단계 갱신
- [ ] 다국어 지원 (영어 우선)
- [ ] 서류 양식 작성 도움 (기관 제출용)
- [ ] 만료 알림 (비자, 등록증)

## 만들 수 있을까
- 필요한 기술/API: LLM (상태 해석·설명 생성), 의존성 그래프는 직접 정의한 데이터로 충분 (외부 API 불필요), 지도 API (기관 위치)
- 하루 안에 데모까지 갈 수 있는가: 가능성 높다. 그래프 데이터를 직접 만들고 위상 정렬로 순서를 뽑는 구조라 외부 의존이 적다. 데모에서 "막혔던 순환을 풀어주는" 장면이 명확하게 보인다.
- 걸림돌
  - 절차 규칙이 은행·통신사별로 다르고 자주 바뀐다. 그래프 데이터의 정확도와 최신성이 서비스 신뢰도를 결정한다.
  - 데모용으로는 대표 경로 몇 개만 정확히 담고, 범위를 명시하는 편이 안전하다.
  - 실제 규정을 잘못 안내하면 사용자가 헛걸음이나 금전 손해를 본다. 출처와 확인 시점을 함께 보여줘야 한다.
  - 개인정보(비자 상태 등)를 다루므로 저장 범위를 최소화해야 한다.
