# 🎲 무작위성 주입기 (Randomness Injector)

> 일상에 통제된 카오스를 추가하는 웹 서비스

## 💡 핵심 컨셉

예측 가능한 일상에서 벗어나 삶에 작은 무작위성을 주입함으로써 새로운 경험과 자극을 제공하는 서비스입니다. 단순한 랜덤 추천이 아닌, **의미 있고 실행 가능한 미션**을 통해 사용자의 일상을 더 흥미롭게 만듭니다.

---

## 🎯 주요 기능

### 1. **오늘의 랜덤 미션**
- 매일 또는 원할 때마다 새로운 미션 받기
- 난이도별 분류 (쉬움/중급/도전)
- 카테고리별 필터링 가능

### 2. **식당 룰렛** 🍽️
- 반경 설정 (500m ~ 5km)
- 랜덤으로 식당 선택 (거부 불가 모드 옵션)
- "오늘은 여기서 먹어야 해!" 강제성 부여
- 미방문 식당 우선 추천

### 3. **관계 셔플** 💬
- 1년간 연락 안 한 친구 랜덤 선택
- "오늘 이 친구에게 연락해보세요" 알림
- 연락 이유 자동 생성 (아이스브레이커)
- 관계 복원 성공률 추적

### 4. **스킬 가챠** 🎨
- 매주 새로운 스킬 배우기 챌린지
- 요리, 코딩, 악기, 언어, 운동 등 다양한 카테고리
- 7일 동안 매일 15분 연습 미션
- 완료 시 "스킬 카드" 수집

### 5. **랜덤 미션 예시**
- 🚶 "출근길에 빨간 옷 입은 사람에게 칭찬하기"
- 📚 "도서관에서 눈 감고 랜덤으로 책 한 권 빌리기"
- ☕ "평소 안 가던 카페에서 메뉴판 안 보고 주문하기"
- 🎵 "출근길에 평소 안 듣던 장르의 음악 듣기"
- 🗣️ "오늘 하루 긍정적인 말만 하기"
- 🎭 "점심시간에 모르는 사람과 대화 시작하기"
- 🏃 "다른 경로로 출근/퇴근하기"
- 🎨 "30분 동안 창의적인 낙서하기"

### 6. **운명 공유 모드** 👥
- 친구들과 같은 랜덤 미션 받기
- 함께 미션 완료 시 보너스 포인트
- 실시간 진행 상황 공유
- 팀 대결 모드

### 7. **완료 미션 지도** 🗺️
- 내가 완료한 미션 위치 시각화
- "예측 불가능성 점수" 계산
- 히트맵으로 활동 범위 표시
- 월별/연도별 리포트

## 🎮 게이미피케이션 요소

### 레벨 시스템
- **Lv.1 일상인** (0-10 미션)
- **Lv.2 모험가** (11-30 미션)
- **Lv.3 카오스 마스터** (31-70 미션)
- **Lv.4 자유인** (71-150 미션)
- **Lv.5 예측불가** (151+ 미션)

### 뱃지 수집
- 🔥 "7일 연속 미션 완료"
- 🌍 "10개 이상 다른 동네 탐험"
- 👥 "5명 이상과 미션 공유"
- 🍜 "30개 다른 식당 방문"
- 🎭 "10개 이상 '도전' 난이도 미션 완료"

### 카오스 레벨
- 완료한 미션의 난이도와 다양성을 기반으로 계산
- 일상의 예측 불가능성을 수치화
- 친구들과 카오스 레벨 비교

## 🛠️ 기술 스택

### Frontend
- **HTML5/CSS3/JavaScript (Vanilla)**
- **Web Geolocation API** (위치 기반 기능)
- **LocalStorage** (미션 히스토리 저장)
- **Canvas API** (통계 시각화)
- **Web Notifications API** (미션 알림)

### 확장 가능한 기술
- **Google Maps API** (지도 표시, 식당 검색)
- **Kakao Local API** (주변 식당 정보)
- **OpenAI API** (맞춤형 미션 생성)
- **Firebase** (사용자 데이터 동기화)
- **PWA** (모바일 앱처럼 설치)

## 📱 주요 사용 시나리오

### 시나리오 1: 직장인 김씨
```
아침 출근 전 → "오늘의 미션" 확인 
→ "평소 안 가는 카페에서 커피 주문하기"
→ 새로운 카페 발견, 단골 카페에서 벗어남
→ 미션 완료 후 성취감 + 새로운 장소 경험
```

### 시나리오 2: 대학생 이씨
```
친구들과 점심 메뉴 고민
→ "식당 룰렛" 실행
→ 랜덤으로 선택된 태국 음식점
→ 처음 먹어보는 음식 경험
→ 친구들과 새로운 추억 생성
```

### 시나리오 3: 프리랜서 박씨
```
일주일째 집에만 있음
→ "모험" 카테고리 미션 받기
→ "지하철 한 정거장 먼저 내려서 걷기"
→ 동네 산책하며 새로운 공간 발견
→ 일상에 변화 추가
```

## 🌟 차별화 포인트

### 기존 서비스와의 차이
| 기능 | 일반 To-Do 앱 | 음식 추천 앱 | 무작위성 주입기 |
|------|---------------|--------------|----------------|
| 목적 | 생산성 | 편의성 | **새로운 경험** |
| 선택권 | 사용자 결정 | 여러 옵션 제시 | **랜덤 강제** |
| 재미 요소 | 없음 | 보통 | **게임화** |
| 관계 기능 | 없음 | 없음 | **있음** |
| 성장 추적 | Task 완료 | 방문 기록 | **예측불가능성 지수** |

### 핵심 가치
1. **탈루틴화**: 반복되는 일상에서 벗어나기
2. **세렌디피티**: 우연한 발견의 즐거움
3. **실행 가능성**: 현실적으로 할 수 있는 미션
4. **재미와 성장**: 즐기면서 새로운 것을 배우기
